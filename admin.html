Pengelola Portal

Halaman ini untuk mengubah atau menghapus daftar aplikasi dan mengganti kode akses portal. Hanya bisa dibuka dengan kode kelola; kode lihat tidak berlaku di sini. Tidak ada yang tersimpan otomatis: hasilnya adalah file data.enc.js baru yang Anda unggah ke GitHub. Kembali ke halaman masuk.

1 Muat data yang ada

Masukkan kode kelola yang berlaku sekarang untuk membuka daftar aplikasi yang sedang tayang. Kode lihat (yang dibagikan ke pengguna) tidak bisa dipakai di sini.

2 Daftar aplikasi dan pengaturan

Kategori yang sama akan dikelompokkan dalam satu tab. Ikon boleh dikosongkan (inisial otomatis), satu emoji, atau nama file di folder logos/ seperti logos/sap.png.

3 Kode akses dan buat file

Ada dua kode. Kode lihat dibagikan ke pengguna: hanya bisa membuka portal. Kode kelola dipegang pengelola: membuka portal dan halaman ini untuk mengubah atau menghapus data. Keduanya harus berbeda; huruf besar dan kecil dibedakan. Biarkan seperti terisi kalau tidak ingin mengganti.

  1. Simpan file data.enc.js yang baru saja diunduh.
  2. Di GitHub, buka repository portal, klik Add file → Upload files, seret file itu (menggantikan yang lama), lalu Commit changes.
  3. Tunggu sekitar satu menit; portal akan memakai daftar dan kode akses yang baru. Semua pengguna yang sedang masuk akan diminta memasukkan kode lagi.
